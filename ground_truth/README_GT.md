# 정답지 (Ground Truth / Answer Key) — DELTA roll 데이터 (2026-09-22-16-42-32)

**중요: 실제 영상의 정답은 엔코더/IMU로 측정한 값이 아니다.** 아래는 (1) 공급 이벤트와 교수님이 알려준 물리 제약(막대는 지면에 수직,
센서-축 거리)에서 독립 방법 여러 개로 만든 *기준(reference)* 이고, (2) 정답을 아는 *합성 데이터*다. 둘의 신뢰도는 다르다.

## 1. 회전각 기준표 `theta_reference.csv`  (실제 영상, 기준 = 추정)
- `theta_ref_deg`: 최종 기준 θ(t). 4ms 창 중앙 시각(`t_ms`)별 장면의 영상 내 롤 회전각(도, 시작=0, 증가 방향 = 장면이 도는 방향).
  ECC 증분(현수 방법 재현) + CMax 증분 + 선 방향 절대각을 가중 최소제곱으로 결합, 모델 복잡도는 시간 블록 교차 검증으로 선택
  (`scripts/delta_theta_ls.py`, progress.md §163).
- `theta_ecc_deg`(ECC 단독), `theta_tracker_deg`(맵 정합), `theta_fused_earlier_deg`(앵커+CMax 모양)은 독립 비교용.
- `band_min_deg/band_max_deg`: 네 추정의 최소/최대 = **불확실 구간**. 300~1500ms에서 중앙값 약 5도, 최대 13도.
  총 회전량: 기준 322.1, ECC 322.9, 추적기 322.3, 앞선 결합 328.1, (현수 보고 323).
- 사용법: 프레임을 θ만큼 되돌리려면 `cv2.getRotationMatrix2D((480,360), +theta, 1.0)` 후 `warpAffine`. 막대가 수직으로 선다.
- 한계: 진짜 절대각 정답은 없음. 합성에서 각 추정기의 오차는 알려져 있음(ECC -4%, 선 방향 정확(축정렬 장면)이나 실제 원근선 장면에서 편향,
  CMax -21%, 결합 RMS 0.69도). 실제 영상의 오차는 구간별 band로만 가늠 가능.

## 2. 기준 프레임 `reference_frames/`, `reference_frames_montage.png`
- 20ms 이벤트 누적 프레임(극성 합, ±3 클립)을 기준 θ로 되돌린 영상, 200~1400ms 100ms 간격. 막대 3~4개, 가운데 마운트 케이지,
  원근의 구멍판이 모든 프레임에서 같은 모습으로 서야 정렬이 맞는 것. 월드맵 결과를 이 장면과 눈으로 대조한다.
- 한 프레임에는 시차가 있어 프레임마다 막대의 가로 위치가 약간 다르다(센서가 축에서 4 벗어나 돌기 때문).

## 3. 장면 기하 `scene_geometry.json`
- 슬라이드(`Q&A/3차/rotation_setup.pptx`): 물체1~4-축 47.5/48.5/50.5/55, 센서-축 4(단위 미표기). 센서 960x720, 렌즈 6mm, 프레임 주기 773us,
  읽기 순서 = 컬럼(x) 순차, 프레임당 타임스탬프 1개(원본 .dvs 해독, `scripts/external/hyunsu_decode_dvs.py`).

## 4. 합성 정답 `synthetic/`  (진짜 정답, 모델이 정확히 아는 세계)
- `syn_truth.npz`: 장면 요소(선분/점)와 깊이 s, 센서 오프셋(방향 125도, 중심(470,372)), 정답 θ(t)(= 실제 θ_ref 시간 프로파일 재사용).
- `syn_truth_scene.png`: 정답 월드맵(공통 좌표계 u=Q). 생성기 `scripts/synth_scene.py`, 평가 `scripts/synth_evaluate.py`.
- 이벤트 파일(`syn.h5`, 약 200MB)은 용량 때문에 저장소에 없음: `python scripts/synth_scene.py <theta.npy> <omega.npy> <out.h5> <truth.npz>` 로 재생성.

## 5. 평가 지표 정의 (월드맵 결과를 이 정답지로 채점)
- **세로선 연속성**: 맵 중앙 720x960 영역에서 수직 에지 에너지 상위 N개 열의 세로 연속 길이(25% 임계, 15px 닫힘) 중앙값, N=6/10/15를
  모두 본다. 실제 프레임 기준 중앙값 약 280px, 합성 정답 장면 287px. (N=6만 보면 열 선택에 흔들림.)
- **복사본 높이**: 맵 영역의 대역통과 자기상관에서 (19,-20)px 주변 최대값(영역 A/C/D 평균), 이전 파이프라인의 월드 고정 복사본(약 28px). 낮을수록 좋음.
- **합성 정답 NCC**: 파이프라인 월드맵과 `syn_truth_scene`의 대역통과 NCC(+-20px 이동 탐색). 합성 θ 정확도 개선 시 0.16 -> 0.37.
- 주의: 선명도 지표 sum(c^2)/sum(c)는 이벤트 수와 맵 면적에 흔들려 비교에 부적합(progress.md §149, §150).

# 키프레임(SLAM) 방식 -- 실제 DELTA 영상 시험, 사전 등록 기준 (2026-10-27, K 실행 전에 커밋)

배경: 합성 시험(criteria.md, progress.md §225)에서 K는 기준 미통과. 실제 영상에서는 시차·잡음·불규칙 속도 때문에 현재 설계(B1)가
드리프트를 남길 수 있으므로 같은 질문을 실측으로 다시 묻는다. 정답 각도가 없어 비지도 지표(앞/뒤 절반 지도 정합)를 쓴다.

## 시험 조건 (결과를 보기 전에 고정)
- 데이터: `Q&A/3차/extracted/2026-09-22-16-42-32-DELTA.h5` (960x720, 1.6 s, 7,533만 이벤트, 회전 약 324도). 단일 영상이며 전체 구간 사용.
- 공통 앞단: `delta_rotation_cmax.py`의 4 ms 창 각속도(omega, 이것이 예측값). 회전중심 = 영상 중심(CX,CY), 캔버스 1200x1200, 창당 20,000 이벤트 서브샘플(시드 0).
- B1: `scripts/delta_map_track.py`의 `track()` 그대로(재구현하지 않음).
- K(= K-coarse): 합성 시험과 같은 구조 -- 키프레임 간격 3도, 이벤트별 작은 각도 보정(theta_mid + om*dt 사용, B1과 동일), 로컬 키프레임 2장 맵으로 추적(탐색 +-1.5도, 0.25도 간격, 점수 = log1p+가우시안 sigma 2 블러 맵 합, 동점이면 |d| 작은 쪽),
  루프 클로저 규칙 고정(NCC >= 0.5, 2등 봉우리 대비 1.5배, 후보 각도 차 10도 이내, 인덱스 차 > 5, 탐색 +-6도), 1차원 자세 그래프(가중 최소제곱, 합성 시험과 같은 가중).
- 평가(`delta_eval_halves.py`와 같은 전처리): 시간 0.795 s 기준 앞/뒤 절반 이벤트로 각각 월드맵 A,B를 만들고(99 백분위 클립, DoG(2,12), 반지름 450 마스크),
  B를 -4..+4도(0.5도 간격)로 돌려 A와 NCC. B1은 이벤트별 theta(t) 보간으로, K는 앞/뒤 절반에 속하는 키프레임을 자세 그래프 보정 각도로 합성(키프레임은 생성 시각 기준으로 절반 배정).

## 판정 기준
- D0 재현: B1의 NCC@0도가 0.239 +-0.02, 최대 NCC 회전이 0도(+-0.5). 어긋나면 파이프라인 불일치로 보고 K 판정을 보류하고 원인부터 조사.
- D1 이득: K의 최대 NCC 회전이 +-2도 이내 **그리고** NCC@0도가 B1의 1.10배 이상(0.263 이상)이어야 "이득 있음". 1.10배 미만이면 이득 없음(기각), 0.90배 미만이면 악화.
- D2 일관성: 보정된 K 각도와 B1 각도의 최대 차 <= 3도. 넘으면 두 방법이 서로 다른 해를 내므로 원인 조사 후 보고(판정은 D1 우선).
- D3 루프 클로저: 수락된 루프 클로저 >= 3개, 그리고 자세 그래프 최적화 후 루프 잔차 RMS <= 1도(정답 없이 내부 일관성만 봄).
- 결론 규칙: D0 통과 + D1 이득 + D3 통과 일 때만 "실측에서 이득 확인". 아니면 키프레임 방식은 합성과 실측 모두에서 기각으로 확정. 시험 후 임계값 조정은 별도 이름의 새 사전 등록으로만.
- 진단(판정 아님): 루프 클로저 후보의 NCC 분포(수락/기각 이유), 키프레임 수, 추적 시간.

# 현수 자기보정(job26 EstU, 부트스트랩 피벗 추정)의 독립 검증 -- 사전 등록 기준 (2026-10-30, 실행 전 커밋)

질문: 현수의 자기보정이 (1) 피벗 위치를 데이터에서 복원하는가, (2) 다른 녹화의 기하 상수를 그대로 쓴 "프리즈"보다 일반화되는가.
현수 문서의 주장(job26_generalization.md): roll에서 자기보정 0.67° vs 재맞춤 0.62°, 프리즈(다른 녹화 상수) 61.2°. 이를 **정답이 있는 합성 장면**에서 다시 본다.

## 시험 조건 (결과를 보기 전에 고정)
- 코드: `scripts/external/hyunsu_job26/`(현수 job18_est.py, job26_est.py 무수정). 센서 960x720, 중심 c=(480,360), 프레임 773 us, 이벤트는 프레임 번호만 가짐.
- 합성: 단일 깊이의 선분 60개 + 점 80개(월드 좌표, 넓은 영역), 센서가 피벗 Q 주위로 회전: p = Q + R(-th)(w - Q), u_true = c - Q.
  th(t)는 0 -> 120° 코사인 이징 한 방향(700프레임, 최대 약 0.26°/프레임), 이벤트는 프레임 안의 참 시각 각도로 생성, 프레임당 6,000개, 위치 잡음 0.6 px, 배경 잡음 3%.
- 기하(피벗 u_true, px): G0=(0,0), G1=(50,0), G2=(0,-60), G3=(-45,35), G4=(120,-90). 시드 0,1,2.
- 설정: (S) 자기보정(기본 EstU, 상수 0개), (R) 재맞춤 = 참 u를 `rot1`로 미리 줌, (F) 프리즈 = 현수 칩의 roll 피벗 (480,352) 즉 u=(0,8)을 `rot1`로 미리 줌(다른 녹화/장치의 상수를 그대로 쓴 경우의 대리).
- 각도 오차: 추정 th 궤적과 참 th(t)의 차이(첫 창 기준 0으로 맞춤, 부호 규약은 G0에서 한 번 정해 모든 시험에 동일 적용), 평균 절대오차(deg).

## 판정 기준
- P1 피벗 복원: (S)의 복원 u와 u_true 차이 <= max(10 px, 0.2 x |u_true|), G1~G4에서 시드 3개 중 2개 이상이 모든 기하에서 만족.
- P2 일반화: (S)의 평균 절대 각도 오차 <= max(1.0°, 1.5 x (R)의 오차) 가 5개 기하 모두에서 시드 중앙값 기준 성립.
- P3 상수가 중요함을 확인: (F)의 오차가 (S)의 3배 이상인 기하가 |u_true - (0,8)| >= 40 px인 기하(G1,G2,G3,G4) 중 2개 이상.
- P4 모드 선택: (S)가 1자유도 회전(rot1)을 고른다(r2 >= 0.9), 5개 기하 x 시드 3개 중 12개 이상(80%).
- 결론 규칙: P1~P4 모두 통과하면 "자기보정이 합성에서도 일반화됨(현수 주장 지지)". 하나라도 실패하면 어느 것이 실패했는지를 그대로 보고하고, 조정은 새 이름의 변형으로 따로 사전 등록.
- 한계(미리 명시): 합성은 단일 깊이/한 방향 회전/시차 없음, 현수의 pan 문제(R~21,700 px)는 이번 시험 범위 밖, 정수 칩이 아니라 float 복제 모델.

# 현수 자기보정 -- 먼 피벗(pan 유사) 변형, 사전 등록 기준 (2026-10-30, 실행 전 커밋)

배경: 주 시험(criteria.md)의 기하는 피벗이 최대 약 150 px라 칩 roll 피벗을 프리즈해도 손해가 작을 수 있다. 현수 데이터의 61° 붕괴는 roll(R~49 px)과 pan(R~21,700 px)처럼
피벗이 수백 배 다른 녹화를 서로 바꿔 쓴 경우다. 그 상황(먼 피벗, 작은 회전각)을 합성 정답으로 만든다. 현수 문서는 pan에서 자기보정이 R을 못 구한다고(추정 5k~32k, 참 21.7k) 적었다.
- 기하(피벗 u_true=c-Q, px / 회전각 범위): V1 (1500,-400) / 20°, V2 (6000, 0) / 8°, V3 (20000,-1000) / 5°. 장면 영역은 센서 이동량을 덮도록 키우고 선분 수를 면적에 비례(기준 60개 / 2000x1600 px).
- 나머지 조건(센서 960x720, 700프레임, 프레임당 6,000개, 잡음, 시드 0,1,2, 설정 S/R/F, F = 칩 roll 피벗 u=(0,8) 프리즈)은 주 시험과 같다.
- 판정:
  - Q1 피벗 복원: (S)가 선택한 모드가 rot1이고 |u_est|가 참 |u|의 +-30% 이내, 방향 오차 10° 이내 -- V마다 시드 3개 중 2개 이상.
  - Q2 일반화: (S) 평균 각도 오차 <= max(1.0°, 3 x (R)의 오차) -- V마다 시드 중앙값.
  - Q3 프리즈 붕괴: (F)의 오차가 (S)의 3배 이상(또는 (S)가 rot1 아닌 3-DOF면 (F) 오차가 (R) 오차의 3배 이상) -- V1~V3 중 2개 이상.
- 결론 규칙: 주 시험과 같다. 실패한 기준은 그대로 보고하고 사후 조정은 새 이름으로 따로 등록한다. 한계: 합성은 단일 깊이, 한 방향 회전, 시차 없음, float 복제 모델.

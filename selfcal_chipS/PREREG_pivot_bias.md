# 사전 등록: 자동 피벗 편향 개선 (2026-11-16, 결과를 보기 전에 작성)

**문제**: 새 칩의 자동 피벗 (489,395)의 roll 각도 오차가 0.758 deg로, 손 피벗(480,352) 0.467 deg, float 자기보정(473,408) 0.404 deg보다 나쁨(progress §241). 원인 가설: 정수 3-DOF 관측의 각도(th) 잡음에 의한 회귀 희석(R 28~39 대 float 54.7).

**평가 지표(고정)**: `scripts/selfcal_ecc_pivot.py` 방식, roll 영상에서 정수 기준모델(job24_est roll 모드)에 피벗을 넣어 얻은 평균 절대 오차(err_all, deg). 이 지표는 피벗 후보를 고르는 데 쓰지 않고, 데이터만으로 피벗을 내는 규칙을 고정한 뒤 그 결과를 채점하는 데만 씀.

**후보 규칙**: 각 규칙은 칩이 가진 관측(th, tx, ty, 윈도우 단위)만 입력으로 받고, 정답 궤적이나 사람이 정한 상수를 쓰지 않음. 규칙을 바꾼 뒤 지표를 본 결과로 다시 규칙을 고치면 그 사실을 기록하고 최종 보고에서 "탐색 후 선택"으로 표기.

**합격 기준(코드 작성 전 고정)**:
1. roll 영상: 규칙의 피벗 오차 < 0.467 deg(손 피벗)이어야 "개선", < 0.60 deg이면 "부분 개선", 그 외 "실패".
2. 일반화: 합성 정답 장면(진짜 피벗 알려진 장면, freeze 8~116 deg 시험 세트)에서 피벗 복원 오차가 현재 규칙보다 나쁘지 않아야 함. 단일 영상에서만 좋아지는 규칙은 채택하지 않음.
3. pan 영상: 현재 동작(r2 < 0.9로 3-DOF 유지, 보정 미승인)이 바뀌면 안 됨.
4. 정수 구현 가능성: 누산기 폭과 연산이 RTL(est_selfcal)에 들어갈 수 있어야 하며, 정수 모델이 규칙의 비트 정확 기준이 되어야 함.

**RTL 변경 판단**: 기준 1~3을 통과한 규칙이 있을 때만 est_selfcal 변경, 풀칩 재합성/P&R/LEC/게이트 시뮬을 다시 수행. 통과 규칙이 없으면 "정수 3-DOF 관측으로는 편향을 줄이지 못함"으로 기록하고 RTL은 건드리지 않음.

**사전 기술 분석(후보 아님)**: 피벗 평면 오차 지형(grid scan)은 현상 파악용이며 규칙 선택에 사용하지 않음.
